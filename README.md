# Local CPU Sentiment AI Demo

This example demonstrates how to run a small, open-weight AI model for sentiment analysis entirely on your local CPU. It aligns with the EcoSloth AI philosophy of repurposing older hardware for sustainable and privacy-preserving AI applications, avoiding cloud dependencies and promoting hardware reuse.

## Language

`python`

## How to Run

1. Install dependencies: pip install transformers torch
2. Run the script: python main.py
